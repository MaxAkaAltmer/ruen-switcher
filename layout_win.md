# Windows-клиент для умного исправления раскладки клавиатуры

Фоновый скрипт для Windows, который перехватывает нажатия клавиш **Scroll Lock** и **Pause**, автоматически забирает выделенный текст и отправляет его на локальный или удаленный сервер FastAPI для инверсии раскладки или исправления опечаток.

## 🚀 Возможности
*   **Работает в фоне**: Благодаря расширению `.pyw` скрипт работает без открытия черного окна консоли.
*   **Умный захват текста**: Использует системный механизм Windows *UI Automation* для надежного копирования текста напрямую из активных окон (Блокнот, браузеры, мессенджеры).
*   **Без прав администратора**: Скрипт не требует повышенных привилегий и запускается в обычном режиме пользователя.
*   **Автозапуск**: Интегрируется в систему и стартует автоматически при включении ПК.

## 🛠 Установка и настройка

### Шаг 1. Установка Python
Если у вас еще не установлен Python:
1. Скачайте актуальную версию Python для Windows с [официального сайта](https://python.org).
2. При установке **обязательно отметьте галочку "Add python.exe to PATH"** (Добавить Python в переменные среды).

### Шаг 2. Установка зависимостей
Откройте командную строку (нажмите `Win + R`, введите `cmd` и нажмите Enter) и выполните следующую команду для установки необходимых библиотек:

```bash
pip install keyboard pyperclip uiautomation
```

### Шаг 3. Подготовка скрипта
1. Создайте текстовый файл и назовите его, например, `layout_fixer.pyw` (расширение `.pyw` важно, чтобы скрипт работал скрытно).
2. Вставьте в него код вашего клиента.
3. Убедитесь, что в начале файла указаны корректные IP-адреса вашего FastAPI сервера:
   ```python
   API_URL_FIX = "http://127.0.0.1:18888/fix"
   API_URL_INVERT = "http://127.0.0.1:18888/invert"
   ```

## ⚙️ Добавление в автозапуск Windows

Чтобы скрипт автоматически запускался в фоновом режиме при каждом включении компьютера:

1. Нажмите комбинацию клавиш **Win + R**.
2. Введите команду `shell:startup` и нажмите **Enter**. Откроется системная папка автозагрузки.
3. Перетащите в эту папку ваш файл `layout_fixer.pyw` (или создайте на него ярлык).

*Готово! Теперь при следующем входе в Windows скрипт запустится сам без лишних окон и запросов.*

## ⌨️ Использование

1. Выделите мышкой или комбинацией `Shift + стрелки` некорректный текст в любом приложении (например, написанный не в той раскладке: `ghbdtn`).
2. Нажмите горячую клавишу:
   *   **Scroll Lock** — для инверсии раскладки (перевода выделенного текста на другой язык).
   *   **Pause / Break** — для умного исправления опечаток и грамматики через сервер.
3. Скрипт автоматически заменит выделенный текст на исправленный вариант от сервера.

## 🛑 Как остановить или перезапустить скрипт

Так как скрипт работает без графического окна, его нельзя закрыть обычным крестиком.

1. Откройте **Диспетчер задач** (`Ctrl + Shift + Esc`).
2. Перейдите на вкладку **Подробности** (Details).
3. Найдите в списке процесс **`pythonw.exe`**.
4. Нажмите по нему правой кнопкой мыши и выберите **Снять задачу** (End task).
